# Lộ trình học C#

**Cha:** file solution `LearnC-Nam.slnx` (mở trong IDE). **Con:** các project trong thư mục `src/` — mỗi phần một console app riêng, build/run độc lập.

| Thư mục / Project | Nội dung gợi ý |
|-------------------|----------------|
| `01-NenTang` | Biến, kiểu, toán tử, nhập xuất console |
| `02-DieuKhien` | if/switch, vòng lặp |
| `03-MangVaCollection` | array, List, Dictionary |
| `04-OOP` | class, struct, kế thừa, interface |
| `05-XuLyLoi` | try/catch, throw |
| `06-LinqVaFile` | LINQ cơ bản, File/Stream |
| `07-Async` | async/await (nâng cao dần) |

Chỉnh sửa bảng trên cho khớp với giáo trình bạn đang theo.
